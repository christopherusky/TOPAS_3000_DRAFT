# TOPAS 3000A — C# / .NET AsyncAPI Client

Runnable scenario snippets for consuming TOPAS 3000A AMQP 1.0
messages from C# / .NET 8, using the AMQPNetLite client.

## Layout

- `sdk/` — **not present yet**: a typed C# SDK is deferred to a
  follow-up sub-project. Each snippet parses incoming JSON
  to `System.Text.Json.JsonDocument` / `JsonElement`; once the SDK
  ships, swap the `JsonElement` access for
  `JsonSerializer.Deserialize<T>(...)` into the generated record.
- `snippets/s1.cs` — subscribe to `detector.measurement` and print messages.
- `snippets/s2.cs` — subscribe to `*.fault` (all faults across all domains; A8).
- `snippets/s3.cs` — publish a VMS DisplayMessage and await the correlated response (A4 + A6).
- `snippets/s4.cs` — distinguish sync vs delta messages and detect sync-batch completion (A3 + A5).
- `snippets/s5.cs` — subscribe to `traffic-signal.measurement` (DATEX-II 2017 profile).
- `snippets/s6.cs` — subscribe to `transport-link.measurement` and dispatch on the SCOOT/GPS/ANPR `kind` discriminator (F6).
- `snippets/s7.cs` — consume the static network topology across `network.{node,link,zone,path,turn}` and build an in-memory `Dictionary`.

## Setup

The snippets target **.NET 8** and need one NuGet package
(`AMQPNetLite.Core` 2.4.11); JSON parsing uses `System.Text.Json`,
which is built into the SDK.

The canonical, smoke-tested project lives at
[`asyncapi_clients/smoketest/csharp/TopasSnippets.csproj`](../../smoketest/csharp/TopasSnippets.csproj) —
copy it into your project as the starting point. It pins
`AMQPNetLite.Core` 2.4.11, the same version exercised in CI on every
push, and uses `<Compile Include="...output/csharp/snippets/*.cs" />`
to compile all seven snippets in one assembly. A small
`Program.cs` dispatcher in the same directory shows how to pick a
specific scenario at runtime via reflection (`dotnet TopasSnippets.dll S3`).

Build:

```bash
dotnet publish -c Release \
    asyncapi_clients/smoketest/csharp/TopasSnippets.csproj
```

## Run

Set `TOPAS_AMQP_URL` to your broker (defaults to
`amqps://localhost:5671`). For local development against an Apache
ActiveMQ Artemis broker:

```bash
export TOPAS_AMQP_URL=amqps://localhost:5671

dotnet run --project snippets-s1.csproj
dotnet run --project snippets-s5.csproj
```

### Environment variables

| Variable | Default | Used by |
| --- | --- | --- |
| `TOPAS_AMQP_URL` | `amqps://localhost:5671` | all snippets |
| `TOPAS_MAX_MESSAGES` | `5` (S4 uses `20`) | S1, S2, S4, S5, S6 |
| `TOPAS_ORIGINATOR` | `asyncapi-clients-s3-demo` | S3 (sets `x-originator` per A4) |

The names match the Python and Java snippets' env vars so the docs
stay consistent across languages.

## Don't hand-edit

The contents of `snippets/` are generated by
`asyncapi_clients/generator/generate.py`. Re-run with
`make asyncapi-clients` after changing `asyncapi.yaml` or any
template under `asyncapi_clients/templates/csharp/`.
