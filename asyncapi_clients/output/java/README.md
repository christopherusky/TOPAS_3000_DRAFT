# TOPAS 3000A — Java AsyncAPI Client

Runnable scenario snippets for consuming TOPAS 3000A AMQP 1.0
messages from Java, using the Apache Qpid JMS client.

## Layout

- `sdk/` — **not present yet**: a typed Java SDK is deferred to a
  follow-up sub-project. Each snippet parses incoming JSON
  to `com.fasterxml.jackson.databind.JsonNode`; once the SDK ships,
  swap the `JsonNode` calls for `ObjectMapper.treeToValue(...)` into
  the generated record.
- `snippets/S1.java` — subscribe to `detector.measurement` and print messages.
- `snippets/S2.java` — subscribe to `*.fault` (all faults across all domains; A8).
- `snippets/S3.java` — publish a VMS DisplayMessage and await the correlated response (A4 + A6).
- `snippets/S4.java` — distinguish sync vs delta messages and detect sync-batch completion (A3 + A5).
- `snippets/S5.java` — subscribe to `traffic-signal.measurement` (DATEX-II 2017 profile).
- `snippets/S6.java` — subscribe to `transport-link.measurement` and dispatch on the SCOOT/GPS/ANPR `kind` discriminator (F6).
- `snippets/S7.java` — consume the static network topology across `network.{node,link,zone,path,turn}` and build an in-memory `Map`.

## Setup

The snippets need two dependencies: the Apache Qpid JMS client (for
AMQP 1.0) and Jackson's `ObjectMapper` (for JSON parsing). The
canonical, smoke-tested `pom.xml` lives at
[`asyncapi_clients/smoketest/java/pom.xml`](../../smoketest/java/pom.xml) —
copy it into your project as the starting point. It pins
`qpid-jms-client 1.13.0` and `jackson-databind 2.17.2`, the same
versions exercised in CI on every push.

Stage the dependency jars into a `lib/` directory next to the
snippets so the bare `javac`/`java` invocations below work:

```bash
mvn -f path/to/your/pom.xml dependency:copy-dependencies -DoutputDirectory=lib
```

## Run

Set `TOPAS_AMQP_URL` to your broker (defaults to
`amqps://localhost:5671`). For local development against an Apache
ActiveMQ Artemis broker:

```bash
export TOPAS_AMQP_URL=amqps://localhost:5671

# Compile all snippets in one go.
javac -cp "lib/*" -d target snippets/*.java

# Run any one of them.
java -cp "target:lib/*" S1
java -cp "target:lib/*" S5
```

Or, with Maven, install the snippet `.java` files under
`src/main/java` and use the `exec-maven-plugin`:

```bash
mvn compile
mvn exec:java -Dexec.mainClass=S1
mvn exec:java -Dexec.mainClass=S3
```

### Environment variables

| Variable | Default | Used by |
| --- | --- | --- |
| `TOPAS_AMQP_URL` | `amqps://localhost:5671` | all snippets |
| `TOPAS_MAX_MESSAGES` | `5` (S4 uses `20`) | S1, S2, S4, S5, S6 |
| `TOPAS_ORIGINATOR` | `asyncapi-clients-s3-demo` | S3 (sets `x-originator` per A4) |

The names match the Python snippets' env vars so the docs stay
consistent across languages.

## Don't hand-edit

The contents of `snippets/` are generated by
`asyncapi_clients/generator/generate.py`. Re-run with
`make asyncapi-clients` after changing `asyncapi.yaml` or any
template under `asyncapi_clients/templates/java/`.
